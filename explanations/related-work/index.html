RESEARCH PREVIEW 0.5.0rc2

Related implementations¶

Source checks recorded on October 27, 2026. These narrow inspections guide positioning; they are not head-to-head evaluations or claims of superiority.

What was checked: selected source files. What was not checked: complete test suites or another project's model results. Main-branch links can change; the inspected file hashes are retained below.

Temporal Clue¶

The code constructs a temporal/spatial mystery prompt with suspects, weapons, rooms, times, motives, questions and a solution export. Its CP-SAT model enforces:

  • Categorical assignments.
  • Movement adjacency.
  • Weapon movement with suspects.
  • Crime room/time relationships.

These are confirmed features in the inspected files. No broad assertion about absent capabilities follows from inspecting two files; we did not run its generation tests or reproduce its evaluations.

EnigmaForge¶

The generator samples a ground truth, adds consistent relational constraints, strengthens toward uniqueness, and minimizes surviving constraints. Verification code includes:

  • SAT/oracle model-set and uniqueness checks.
  • Ablation and distractor safety.
  • Template realization and round-trip checks.

These overlap with verified puzzle generation and controlled evidence; those features alone are not novelty claims. We did not establish coverage or correctness by executing this source, nor verify its model-performance claims.

Positioning and publication patterns¶

Clue Benchmark focuses on configurable certified information availability, public reliability rules, private/coalition evidence and supported correctness. It does not claim novelty for mysteries, distractors, graphs or verified puzzles in isolation. Reasoning Gym and lm-evaluation-harness are useful onboarding/interface references; Inspect illustrates readable saved records. No adapter compatibility is advertised.

The static docs separate tutorials, practical guides, explanations and reference following Diataxis, with MkDocs search.
